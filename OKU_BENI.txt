J.A.R.V.I.S — Windows EXE Sürümü

KULLANIM
--------
Final Windows sürümünde JARVIS.exe dosyasına çift tıklaman yeterlidir.
Python kurulumu, pip veya BAT dosyası gerekmez.

GELİŞTİRİCİ NOTU
----------------
Windows EXE derlemesi PyInstaller ile yapılır. JARVIS.spec dosyası
JARVIS.ico ikonunu EXE içine gömer.

GÜNCELLEME
----------
JARVIS, GitHub Releases üzerinden yeni sürümü kontrol eder. Yeni sürüm
bulunursa mevcut EXE kapanır, güncelleme uygulanır ve güncellemenin
tamamlandığını belirten mesaj gösterilir. Kullanıcı JARVIS.exe'yi yeniden
başlatır.

ÖZELLİKLER
----------
• Gerçek zamanlı sesli sohbet (Gemini)
• Yazılı komutlar
• Windows ana ses seviyesini yüzde bazında ayarlama
• Uygulama açma ve sistem araçları
• Ekran analizi ve webcam
• YouTube/Spotify'da medya açma
• Kalıcı hafıza
• Takvim ve hatırlatıcı web bağlantıları
• Masaüstü kısayolu ve Windows başlangıcında çalıştırma
• GitHub otomatik güncelleme

KISAYOLLAR
----------
F4  Mikrofonu sustur/aç
F5  Duraklat/devam et
F6  Webcam'i aç/kapat
F11 Tam ekran
ESC Tam ekrandan çık

NOT
---
YouTube oynatma özelliği korunmuştur. Arayüzdeki sosyal/reklam butonları
kaldırılmıştır.
